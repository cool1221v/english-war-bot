
# English War Bot - Phase 1

## Features

- B2–C2++ level quiz system
- XP, level, and rank system
- Nickname registration
- Bronze, Silver, Gold, Diamond, Gem economy
- Mystery box, task, and reward logic

## Setup Instructions

1. Install requirements:
```
pip install -r requirements.txt
```

2. Add your bot token to config.py
```
TOKEN = 'YOUR_BOT_TOKEN_HERE'
```

3. Run the bot:
```
python main.py
```

Default DB is `main.db` and created automatically.
